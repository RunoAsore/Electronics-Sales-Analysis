## Project Overview

This Power BI dashboard analyzes electronics sales data to provide actionable insights into revenue, profitability, customer purchasing behavior, and regional sales performance.

## Objectives
- Monitor sales performance across products.
- Analyze customer purchasing trends.
- Identify profitable products and regions.
- Support business decision-making through interactive reporting.

**Tools Used**
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling

**Key Performance Indicators (KPIs):**
- Total Revenue
- Total Profit
- Total Customers
- Average Sales
- Sales Quantity

**Dashboard Features:**
- Revenue Trend Analysis
- Product Performance
- Customer Analysis
- Regional Sales Analysis
- Profitability by Product

**Key Insights:**
- Certain product categories consistently generated higher revenue.
- Sales performance differed across regions.
- Customer purchasing patterns highlighted high-value products.
- Profitability analysis identified the best-performing products.
